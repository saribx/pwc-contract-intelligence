# PwC Contract Intelligence

Prototyp-Dashboard, das aus unstrukturierten Verträgen (PDF, Scan und weitere Formate) eine auswertbare Wissensbasis macht. Entstanden im Workshop "Contract Intelligence: Von Verträgen zu verlässlichem Wissen" bei den PwC Tech Days am 30.10.2026.

**Funktionen:** Vertragstabelle pro Mandant mit Fristen, Haftung und Gültigkeitsprüfung, Wissensgraph, Architekturdiagramm, Chat mit den Verträgen, frei definierbare Kategorien.

**Starten:** `index.html` im Browser öffnen. Es gibt keinen Build-Schritt. Die Daten sind Demodaten, die Extraktion ist nicht an ein Backend angebunden.
